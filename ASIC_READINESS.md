# AV1 ASIC Readiness

## Goal

Move the AV1 RTL encoder from a decoder-verified bring-up tree toward a real
ASIC-ready encoder IP block. This is separate from, and comes after, closing
the full codec feature gaps tracked in `FULL_RTL_SCOPE.md`.

The current state is **not ASIC-ready**. The purpose of this file is to keep the
front-end/synthesis path honest while codec features continue to move out of the
software debug writer and into the RTL byte path.

## ASIC Readiness Gates

1. Keep a deterministic RTL file list and top module for the ASIC candidate.
2. Keep a fast frontend smoke that runs on Chud PC 2 without generated artifacts
   committed to the repo.
3. Prefer leaf/module frontend gates before any full-top flattening.
4. Isolate simulation-only/testbench-only behavior from synthesizable RTL.
5. Replace testbench-owned frame/bitstream memories with explicit SRAM/DRAM or
   FIFO-style interfaces before treating the design as ASIC-shaped.
6. Preserve hierarchy for synthesis; do not feed a giant flattened codec blob to
   tools unless the leaf/medium blocks are already known-clean.
7. After codec features are complete, run capped full-top synthesis diagnostics
   on the large-memory host and record peak RSS/tool failures outside the repo.
